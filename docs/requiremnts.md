# Жүйеге қойылатын талаптар

## Функционалдық талаптар

1. Жүйе клиенттен тапсырыс қабылдауы керек.
2. Жүйе тапсырыс туралы ақпаратты сақтауы керек.
3. Менеджер тапсырысты өңдей алуы керек.
4. Жүйе қоймадағы тауардың бар-жоғын тексеруі керек.
5. Жүйе төлем ақпаратын өңдеуі керек.
6. Менеджер тапсырысты курьерге бере алуы керек.
7. Курьер тапсырысты клиентке жеткізе алуы керек.
8. Жүйе тапсырыс мәртебесін көрсетуі керек.

## Функционалдық емес талаптар

1. Жүйе пайдалануға ыңғайлы болуы керек.
2. Жүйе ақпаратты қауіпсіз сақтауы керек.
3. Жүйе тұрақты жұмыс істеуі керек.
4. Жүйе тапсырыс ақпаратын жылдам өңдеуі керек.
5. Жүйе болашақта кеңейтілуі мүмкін болуы керек.
