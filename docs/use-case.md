# Use Case

## Актерлер

- Клиент
- Менеджер
- Курьер

## Негізгі әрекеттер

### Клиент
- Тапсырыс беру
- Тапсырыс мәртебесін тексеру

### Менеджер
- Тапсырысты қабылдау
- Тапсырысты өңдеу
- Қоймадағы тауарды тексеру
- Тапсырысты курьерге беру

### Курьер
- Тапсырысты қабылдау
- Тапсырысты жеткізу
- Тапсырыс мәртебесін өзгерту
