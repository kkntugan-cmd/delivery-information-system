# Жеткізу қызметінің ақпараттық жүйесі

## Жоба туралы

Бұл жоба жеткізу қызметінің жұмысын автоматтандыруға арналған ақпараттық жүйені сипаттайды.

## Жобаның мақсаты

Тапсырыстарды қабылдау, өңдеу және жеткізу процесін ұйымдастыру.

## Негізгі пайдаланушылар

- Клиент
- Менеджер
- Курьер

## Жобаның негізгі мүмкіндіктері

- Тапсырыс қабылдау
- Тапсырысты өңдеу
- Тауардың қоймада бар-жоғын тексеру
- Төлемді ұйымдастыру
- Тапсырысты курьерге беру
- Тапсырысты клиентке жеткізуыыы
